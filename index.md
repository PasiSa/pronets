# Programming Networked Systems course

These pages contain the material and assignments for the **Programming Networked
Systems course (ELEC-C7260)** at Aalto University.

The code examples in this material are provided in the
**[Rust](https://www.rust-lang.org/)** programming language, and use of Rust is
recommended for assignments and project work. If you don't know Rust yet, this
might be a good opportunity to learn it. In the early parts of the course the
essentials of the language will be presented, and there are plenty of good
online learning material available (references given in the material). However,
if you strongly prefer not to use Rust, you can also use C or C++ for the server
implementations. For client implementations you can choose programming language
more freely.

The GitHub repository for the material is
**[available](https://github.com/PasiSa/pronets)**. If you find something to
correct or add, feel free to drop an [GitHub
issue](https://github.com/PasiSa/pronets/issues/new) in the repository, or just
send [E-mail](mailto:pasi.sarolahti@aalto.fi) to the author. For straightforward
fixes (for typos, etc.) you could also do a pull request in GitHub.

The course material contains the following sections:

1. [Introduction and basic network tools](intro/)
1. [Rust basics and client sockets](rust-basics/)
1. [Simple server and Docker containers](server/)
1. [Protocol design and project grouping](protocol/)
1. [Testing and observability](testing/)
1. [Concurrency and asynchronous programming](concurrency/)
1. [Security](security/)
1. UDP and real-time transport
1. Advanced topics

In addition, the course will have interoperability hackathon weeks and final
demo.

**About the use of AI**: On this course there are no restrictions to using AI
tools for developing the program code, as long as you make sure to review and
understand what you are doing. In the weekly assignments you will write up a
short analysis and reflection of your work based on the given guidelines, which
we expect you to do personally with your own thoughts. Note that the course has
exams that are organized in supervised Exam classrooms without access to the
Internet.
